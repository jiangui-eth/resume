# Feature: 国际化（i18n）

**状态**：已实现，使用 next-intl 4.x

## 路由结构

- `/` → 默认重定向到 `/en`
- `/en/` — 英文
- `/zh/` — 简体中文
- `/tw/` — 繁体中文

## 关键文件

| 文件                                | 说明                                          |
| ----------------------------------- | --------------------------------------------- |
| `apps/web/src/middleware.ts`        | next-intl 路由中间件                          |
| `apps/web/src/i18n/routing.ts`      | 路由配置（locales, defaultLocale, pathnames） |
| `apps/web/src/i18n/request.ts`      | 服务端 request config                         |
| `apps/web/messages/{en,zh,tw}.json` | 翻译文案                                      |

## 约定

- 所有页面路由必须在 `src/i18n/routing.ts` 的 `pathnames` 中注册
- E2E 测试直接 import messages JSON，改文案不会破坏测试
- `Link` / `useRouter` / `usePathname` 从 `@/i18n/navigation` 导入（不用 next/link / next/navigation）
